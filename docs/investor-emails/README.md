# Investor emails: MANUAL ONLY

**Joshua sends from his own Gmail.** There is no Gmail OAuth, Gmail API, or automated send in this project until Joshua sets that up separately.

## Files

| File | Purpose |
|------|---------|
| `READY-TO-SEND.md` | 20 copy-paste email blocks (subjects + bodies) |
| `SEND-CHECKLIST.md` | Before/after send workflow and log updates |
| `01-reach-edtech-operator.md` … `05-angel-edtech-operator.md` | Thesis-specific variants |

## Workflow

1. Pick a target from `READY-TO-SEND.md`.
2. Verify the partner email on the firm website (do not use guessed addresses).
3. Copy **Subject** and **Body** into Gmail and click **Send**.
4. Update `INVESTOR_LOG.md` only after you actually sent (`Status` → `Email sent`).

## Not automated

- Discord and Reddit user promotion: `docs/SOCIAL-AUTOMATION.md`
- Public copy for LinkedIn / DMs: `docs/USER-PUSH.md`

Do not mix investor contact details into public Discord or Reddit posts.
